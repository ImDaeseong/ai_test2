# 실제 OpenAI API 검증 증거

## 2026-10-22 — 채널별 초안 생성

- 경로: Windows 실행기 → 로컬 HTTP 서버 → `/api/ai/draft` → OpenAI Responses API
- 입력: 개인정보가 없는 가상 서비스·대상·가치·신뢰 근거·행동 요청
- 모델: `gpt-6-luna`
- 결과: `generated`
- 사용량: 입력 282토큰, 출력 102토큰, 총 384토큰
- 출력 검증: 192자, 행동 요청 포함
- 계산 비용: `(282 × $0.10 + 102 × $0.50) / 1,000,000 = $0.0000792`
- 비밀 경계: API 키와 원시 공급자 응답은 파일·로그·화면에 기록하지 않음

가격 근거: <https://developers.openai.com/api/docs/models/gpt-6-luna>

## 2026-10-22 — 커뮤니티 컨텍스트 초안·평가

- 경로: `start.bat` → 로컬 HTTP 서버 → `/api/ai/draft`, `/api/ai/review` → OpenAI Responses API
- 입력: 개인정보가 없는 가상 서비스와 목표·콘텐츠 주제·커뮤니티 문화·질문·공개 예시 URL·성공 신호
- 모델: `gpt-6-luna`
- 초안 결과: `generated`, 입력 386토큰, 출력 280토큰, 총 666토큰, 520자
- 평가 결과: `reviewed`, 입력 651토큰, 출력 569토큰, 총 1,220토큰, 점수 7, 위험 4개, 개선안 558자
- 응답 구조 검증: 초안 본문과 평가의 점수·첫 줄·설득력·위험·개선안 필드를 프로덕션 파서가 정상 처리함
- 계산 비용: `((386 + 651) × $0.10 + (280 + 569) × $0.50) / 1,000,000 = $0.0005282`
- 비밀 경계: API 키, 전체 프롬프트, 생성 본문, 원시 공급자 응답은 파일·로그·화면에 기록하지 않음
