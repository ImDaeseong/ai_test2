# 게시 전 사람 검수표

자동 검사와 AI 평가는 문안의 실제 반응이나 커뮤니티 운영 규칙을 대신하지 않습니다. 게시할 사람이 채널마다 아래 항목을 확인하고 날짜와 근거를 남깁니다.

## 문안 검수

- [ ] 첫 줄이 실제 대상의 상황이나 얻는 가치로 시작한다.
- [ ] 혜택, 비용, 자격, 후기, 수치가 서비스 설명과 실제 증거 안에 있다.
- [ ] 허위 희소성, 치료·성과 보장, 불필요한 공포나 압박이 없다.
- [ ] 신뢰 근거와 한계가 함께 보이며, 행동 요청은 하나다.
- [ ] 오프라인 만남이라면 장소, 중단 권리, 건강·알레르기 안내를 당사자가 실제로 지킬 수 있다.

## 커뮤니티 검수

- [ ] 게시판의 최신 홍보·모집·링크·광고 표기 규칙을 직접 읽었다.
- [ ] 게시할 계정과 콘텐츠에 필요한 권리·동의가 있다.
- [ ] 전화번호, 주소, 건강정보 등 불필요한 개인정보가 없다.
- [ ] 자동 게시가 아니라 최종 미리보기를 확인한 뒤 사람이 게시한다.

## 게시 후 검수

- [ ] 게시 날짜, 채널, 조회, 반응, 문의를 기록한다.
- [ ] 신고·오해·안전 문제가 생기면 게시를 중단하고 원인을 기록한다.
- [ ] 다음 문안은 실제 반응 기록을 근거로 한 요소만 바꾼다.

## 증거 기록 원칙

- 규칙 검수에는 게시판/커뮤니티 규칙 URL, 확인 날짜, 검수자, 정확한 게시 본문 해시를 남긴다. 본문이 바뀌면 다시 검수한다.
- A/B 실험은 같은 실험 ID 아래 기준안 A와 변경안 B를 기록하고, B에는 바꾼 요소 하나를 적는다.
- 조회수 0 또는 A/B 한쪽 누락은 `HOLD_INSUFFICIENT_EXPOSURE`다. 앱의 `OBSERVED_LIFT`는 원시 전환율 차이이며 통계적 유의성이나 인과효과 주장이 아니다.
- 연동 준비도의 `CONFIGURED`는 로컬 환경변수 이름이 모두 있다는 뜻뿐이다. 플랫폼 심사, 계정 역할, 소유자 동의, 실제 게시 성공은 별도 증거로 확인한다.
- 네이버 블로그 외부 글쓰기는 지원 종료된 API이므로 수동 게시만 사용한다.

## 현재 판정

- 자동 규칙·브라우저 흐름: PASS
- AI 편집 관점 검토: PASS
- 실제 대상 독자 반응: EVIDENCE GATE READY / 실제 노출 데이터 전까지 HOLD
- 실제 커뮤니티 운영자·규칙 검수: EVIDENCE GATE READY / 채널별 사람 기록 전까지 HOLD
- 플랫폼 계정 권한·API 자동 게시: READINESS CHECK READY / 앱 등록, 플랫폼 심사, 계정 소유자의 명시적 동의와 실제 게시 증거 전까지 HOLD
