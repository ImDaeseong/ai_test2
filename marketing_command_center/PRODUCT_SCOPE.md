# 제품 범위와 완료 기준

## 사용 사례

나는 혼자 여러 서비스를 홍보할 때 이 로컬 도구로 대상·가치·신뢰·행동이 분명한 커뮤니티별 글을 만들고, 점검을 통과한 글을 복사해 연결된 게시 화면에서 직접 게시한 뒤 반응을 기록해 다음 글을 개선한다.

## 범위

- 포함: 서비스 저장, 콘텐츠 브리프(대상·가치·신뢰·행동), 6개 채널별 글 작성, 규칙 점검, AI 초안·평가, 그림·영상·음악 수동 점검표, 채널별 HTTPS 게시 주소 저장, 본문 복사 후 게시 화면 열기, 올린 글 기록과 반응 요약, 첫 실행 예시 글.
- 제외: 자동 게시, 외부 계정 권한 연결, 플랫폼 API 게시, 일정·승인 관리, 백업·내보내기, 이미지 저장, 광고 결제, 개인정보 수집.

## 보안 경계

- 서버는 기본적으로 `127.0.0.1`에만 바인딩하고 모든 응답에 CSP, `nosniff`, 프레임 차단, 리퍼러 차단 헤더를 붙입니다. API 응답은 `no-store`, 정적 파일은 `no-cache`로 보냅니다.
- 소스와 검증 문서는 공개 저장소에서 관리하되 실제 API 키, 로컬 로그, 브라우저 저장 데이터와 실행 캐시는 커밋하지 않습니다. 서버는 앱 화면 파일(`index.html`, `styles.css`, `src/*.js`, `assets/*`)만 내보내며 소스, 로그, 문서, 설정 파일 요청은 404로 거절합니다.
- 데이터(서비스 설명, 글, 기록)는 브라우저 `localStorage`에만 저장합니다. 서버는 저장하지 않습니다.
- `OPENAI_API_KEY`는 서버 프로세스 환경변수로만 읽고 응답·로그·화면에 넣지 않습니다.
- AI 호출은 호출마다 사용자 확인을 거치며 입력 길이·출력 토큰을 제한하고 `store: false`로 요청합니다.
- 게시 주소는 브라우저에만 저장하며 `https://`만 허용합니다. 앱은 새 탭을 열고 본문을 복사할 뿐, 계정 자격 증명을 받거나 자동 게시하지 않습니다.
- 외부 게시, 광고 결제, 개인정보 수집, 외부 계정 권한 연결은 하지 않습니다.

## 완료 기준

- 서비스 여러 개를 저장·선택·삭제할 수 있다.
- 처음 열면 "마사지 연습" 서비스와 6개 채널 글이 들어 있고 모두 규칙 점검을 통과한다. 이미 저장된 상태에서는 사용자가 쓴 글을 바꾸지 않고, `예시 불러오기` 버튼으로 다시 불러올 수 있다.
- 채널별로 글이 따로 저장되고, 본문을 쓰면 규칙 점검이 즉시 나오며, 결과 보장 표현이 있으면 "수정 필요"로 막아 해당 단어를 알려 준다.
- 콘텐츠 브리프가 AI 초안에 전달되고, 독자 가치가 없는 글은 규칙 점검에서 경고한다.
- AI 초안과 AI 평가(점수, 첫 줄, 설득력, 위험, 개선안)가 동작하고, 실패 7종이 각각 다른 안내로 보인다.
- 채널별 HTTPS 게시 주소 저장, 본문 복사 후 해당 주소 열기, 올린 글 기록, 조회·반응·전환 입력, 반응이 좋은 곳 요약이 동작하고 새로고침 후 유지된다.
- 스크립트 로드 실패 시 화면에 오류 배너가 표시된다.
- 이전 코드로 실행 중인 서버를 실행기가 교체하고, 정적 파일이 캐시되지 않는다.
- `serve.py`, 로그, 문서, 설정 파일은 GET·HEAD 모두 404이고 앱 화면 파일만 200이다.
- 키 없이 AI 경로가 네트워크를 호출하지 않고 503을 돌려준다.
- 제거된 기능의 용어가 문서·코드에 남아 있지 않다(`npm run validate`).
- 모든 자동 검사(단위, 계약, 수명주기, 실제 Chrome e2e, 런처)가 통과하고, 실제 OpenAI 호출 대표 1회가 통과한다.

## 사람 검토 HOLD

- 규칙·AI 점검 기준이 실제 커뮤니티에서 반응이 좋은 글을 가려내는지(반응 기록으로 장기 확인)
- 각 플랫폼의 계정 권한·게시 API를 이용한 자동 연동은 앱 등록, 권한 심사, 계정별 동의와 실제 샌드박스 검수가 끝날 때까지 HOLD
- 올릴 커뮤니티의 홍보·모집 규칙, 저작권, 개인정보
- 오프라인 만남을 전제로 한 글의 안전 안내가 충분한지, 글에 적은 약속(불편하면 바로 멈춤, 공개된 장소 권장)을 지킬 수 있는지
- 그림·영상·음악 소재의 실제 품질과 사용 권리
