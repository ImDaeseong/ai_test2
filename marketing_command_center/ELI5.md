# 아주 쉽게 설명하면

Hermes Marketing Studio는 여러 홍보 기능을 한 화면에 잔뜩 보여 주는 도구가 아닙니다. 오늘 해야 할 일부터 하나씩 끝내도록 돕는 로컬 글쓰기 도구입니다.

## 어떻게 쓰나요?

1. `오늘`에서 지금 작성 중인 글과 다음 행동을 확인합니다.
2. `콘텐츠`에서 누구에게 어떤 도움을 줄지 적고 글을 씁니다.
3. 필요한 경우 `커뮤니티에 맞게 더 구체화하기`를 열어 그곳의 분위기, 대화를 여는 질문, 근거 URL과 성공 신호를 적습니다.
4. `커뮤니티`에서 과장 표현과 규칙을 확인하고, 본문을 복사해 사람이 직접 게시합니다.
5. `성과`에서 조회·반응·문의 숫자를 기록해 다음 글을 개선합니다.

## AI는 무엇을 하나요?

AI는 입력한 서비스 설명과 브리프 안에서 초안을 만들고 글을 평가합니다. 커뮤니티 목표와 분위기도 함께 참고합니다. 없는 수치·후기·자격을 만들어서는 안 되며, 호출할 때마다 유료 API 사용 확인을 받습니다.

## AI가 하지 않는 일

- 커뮤니티에 자동으로 게시하지 않습니다.
- 최신 게시판 규칙을 자동으로 승인하지 않습니다.
- 미디어 사용 권리나 실제 독자 반응을 대신 판단하지 않습니다.
- API 키를 브라우저나 문서에 저장하지 않습니다.

즉, AI는 글쓰기를 돕고 규칙 검사는 위험을 알려 주지만, 최종 확인과 게시는 사람이 책임집니다.
