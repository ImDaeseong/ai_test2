## 2026-10-22

### 개선

- 단일 긴 화면을 `오늘`, `콘텐츠`, `커뮤니티`, `성과` 작업 화면으로 분리했습니다.
- 첫 화면에는 현재 서비스, 작성 중인 글, 사람 검수 필요 여부와 다음 행동만 표시합니다.
- 서비스 편집과 상세 커뮤니티 브리프를 접힌 보조 영역으로 옮겼습니다.
- 콘텐츠 브리프에 글의 목표, 반복 주제, 커뮤니티 문화, 대화 질문, 근거 URL, 성공 신호를 추가했습니다.
- 확장된 브리프가 AI 초안과 AI 평가 양쪽에 전달되도록 연결했습니다.
- 게시 기록과 성과 입력을 별도 화면으로 이동했습니다.

### 안전 경계

- OpenAI 유료 호출별 확인을 유지했습니다.
- 자동 게시 없이 본문 복사와 게시 화면 열기까지만 지원합니다.
- 본문 해시에 묶인 사람 규칙 검수와 변경 시 무효화를 유지했습니다.
- API 키·전체 프롬프트·생성 본문을 검증 문서에 기록하지 않습니다.

### 검증

- JavaScript 단위 테스트 13개와 Python 단위 테스트 17개를 통과했습니다.
- 계약 검사, 서버 수명주기, 실제 Chrome E2E, Windows 런처 검사를 통과했습니다.
- `gpt-6-luna` 실제 초안 1회와 평가 1회를 실행해 응답 구조를 확인했습니다.
- 상세 토큰 사용량과 비용은 [`LIVE_API_EVIDENCE.md`](LIVE_API_EVIDENCE.md)에 기록했습니다.
