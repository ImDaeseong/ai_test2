# 브라우저에서 공고 원문 가져오기 (북마클릿)

잡코리아·사람인·인크루트는 상세 모집요강을 **브라우저에서 렌더링**합니다. 서버 HTML만 읽는 URL
자동 가져오기로는 요약만 잡히는 경우가 많으므로, **렌더링이 끝난 화면의 원문**을 받는 것이 가장
정확합니다. 가장 쉬운 방법은 다음 둘 중 하나입니다.

## 방법 1: 직접 선택 후 복사 (설치 불필요)

1. 공고 페이지에서 **상세 모집요강 부분을 드래그**해 선택합니다.
2. `Ctrl+C`(맥은 `Cmd+C`)로 복사합니다.
3. CareerDiff의 **채용공고 입력란에 붙여넣습니다**.

## 방법 2: 북마클릿 (한 번 클릭으로 복사)

선택한 텍스트(없으면 페이지 본문 전체)를 클립보드로 복사하는 작은 즐겨찾기입니다.

### 설치

브라우저 즐겨찾기를 새로 만들고, **주소(URL)** 칸에 아래 한 줄을 그대로 붙여넣습니다.

```text
javascript:(function(){var s=(window.getSelection?window.getSelection().toString():'').trim();var t=(s||document.body.innerText||'').replace(/\n{3,}/g,'\n\n').trim();if(!t){alert('추출할 텍스트가 없습니다.');return;}function done(){alert('CareerDiff: 공고 텍스트 '+t.length+'자를 복사했습니다. 채용공고 입력란에 붙여넣어 주세요.');}if(navigator.clipboard&&navigator.clipboard.writeText){navigator.clipboard.writeText(t).then(done,function(){window.prompt('아래 텍스트를 복사하세요 (Ctrl+C):',t);});}else{window.prompt('아래 텍스트를 복사하세요 (Ctrl+C):',t);}})();
```

이름은 `CareerDiff 공고 복사` 등으로 지정합니다.

### 사용

1. 공고 페이지에서 상세 모집요강을 **드래그해 선택**합니다(선택하지 않으면 페이지 본문 전체를
   가져옵니다 — 노이즈가 섞이므로 선택을 권장).
2. 즐겨찾기 `CareerDiff 공고 복사`를 클릭합니다. 복사 완료 알림이 뜹니다.
3. CareerDiff 채용공고 입력란에 붙여넣습니다.

### 원리와 한계

- 사용자의 브라우저에서 이미 렌더링된 DOM 텍스트를 읽으므로, 서버 HTML에 없는 상세 요건까지
  가져옵니다. 로그인 세션이 필요한 페이지도 사용자가 로그인한 상태 그대로 동작합니다.
- 서버로 아무것도 보내지 않으며, 텍스트를 클립보드에 복사만 합니다.
- 일부 브라우저는 즐겨찾기의 `javascript:` 실행을 제한할 수 있습니다. 그럴 때는 방법 1을
  사용하세요.
- 공고가 **이미지**로 등록된 경우 텍스트가 추출되지 않습니다. 화면의 글자를 직접 옮겨 적거나
  다른 텍스트 공고를 사용하세요.
