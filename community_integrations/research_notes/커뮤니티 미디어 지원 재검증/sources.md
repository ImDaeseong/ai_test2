# 공식 출처 판정 메모

확인일: 2026-10-27

- Meta Threads 공식 Postman: TEXT, IMAGE, VIDEO, 최대 20개 혼합 carousel 예시를 확인.
- Meta Instagram 공식 Postman: Professional 계정 게시, Stories는 Business 한정, Reels 서버 게시 흐름 확인.
- Telegram Bot API: sendMessage/sendPhoto/sendVideo/sendAudio/sendDocument 확인.
- TikTok Content Posting API: 영상과 최대 35장 사진, 독립 오디오 게시 없음, 앱 감사·도메인 검증 조건 확인.
- X 공식 문서: v2 media initialize/append/finalize/status 흐름과 `media_id` 첨부 확인.
- KakaoTalk Message: 같은 서비스 사용자 메시지와 이미지 템플릿; 공개 채널 피드 게시와 다름.
- Naver: Blog 글쓰기 종료, Cafe OAuth 글쓰기와 multipart 이미지 예제, Cafe 앱 수동 첨부 확인.
- YouTube Data API: `videos.insert` 확인. Community text/image write는 API 전체 참조에 없어 미지원으로 추론.
- LinkedIn Posts API: text/image/video/document/article 확인, 자산 선업로드 필요.
- Discord webhook: content/embed/files multipart 확인.
- Reddit Developer Platform: text/link/image/video/videogif 제출 유형 확인.
- Facebook Page: 공식 문서 URL은 HTTP 429로 본문 재열람이 제한됨. 코드 계약은 Page Graph의 feed/photos/videos 경계를 사용하되 라이브 테스트 전까지 LOW-EVIDENCE/HOLD.
