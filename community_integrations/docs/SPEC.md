# 제품 범위

## 한 문장 사용 사례

나는 여러 커뮤니티에 같은 소식을 배포할 때 이 도구로 플랫폼별 공식 API 요청을 먼저 검토하고 명시적으로 승인해 게시 결과 ID를 얻는다.

## 보안 등급과 기능

- 노출 등급: T0 로컬 CLI. 수신 포트 없음.
- 외부 기능: 공식 플랫폼 API 호출, 사용자 OAuth/봇 토큰, 공개 HTTPS 미디어 URL.
- 저장 기능: 없음. 토큰·본문·응답을 파일이나 데이터베이스에 저장하지 않음. 따라서 예약 발행·이력·재시도는 아직 비범위.
- 사람 경계: 실제 전송은 `--execute --confirm`을 동시에 요구함.

## 완료 기준

- 13개 플랫폼/서비스 경계의 글·이미지·영상·오디오·파일 지원 여부와 제한이 출처 링크와 함께 문서화된다.
- 지원 플랫폼 요청은 공통 `PublishRequest`에서 공식 엔드포인트 형식으로 변환된다.
- 공식 실행 계약이 없거나 로컬 코드가 완성되지 않은 미디어 흐름은 실행을 차단한다.
- 미리보기·오류 문자열에 토큰이 포함되지 않는다.
- 네트워크 없는 계약 테스트가 모든 어댑터와 사람 확인 게이트를 검사한다.

## 비범위

- CAPTCHA 우회, 브라우저 쿠키 재사용, 화면 좌표 매크로, 비공식 모바일 API.
- 스팸 발송, 무인 대량 예약 게시, 계정 생성 자동화.
- API 앱 심사 대행과 실제 토큰 발급.
- 실제 계정 공개 게시를 자동 테스트에서 수행하는 것.
- OAuth 콜백 서버, 암호화 토큰 저장소, 로컬 바이너리 multipart/resumable 업로드.
