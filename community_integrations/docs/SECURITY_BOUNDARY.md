# 보안 경계

- 실제 토큰은 프로세스 환경변수나 운영체제 비밀 저장소에서만 주입합니다.
- `.env.example`에는 변수 이름과 가짜 자리표시자만 둡니다.
- 요청 미리보기는 `Authorization` 값을 가리고 Telegram Bot 토큰 URL도 `<redacted>`로 표시합니다.
- HTTP 오류는 상태 코드와 경계만 로그에 남기며 응답 본문·토큰·게시 본문은 남기지 않습니다.
- 미디어 URL은 HTTPS만 허용합니다. TikTok은 앱에 등록·검증한 소유 도메인을 사용해야 합니다.
- 토큰에 최소 권한만 부여하고 만료·철회·교체 절차를 플랫폼 콘솔에서 관리합니다.
- 실제 게시 전에 대상 계정, 공개 범위, 저작권, 광고/협찬 표시, 개인정보 포함 여부를 사람이 검토합니다.
- 로컬 CLI는 포트를 열지 않으므로 T0입니다. 향후 웹 서버를 추가하면 127.0.0.1 기본 바인딩, 본문 크기·시간·요청률 제한을 먼저 설계해야 합니다.
