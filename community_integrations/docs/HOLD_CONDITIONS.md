# HOLD 조건

다음 조건에서는 실제 게시를 중단합니다.

- 토큰·계정 ID·대상 채널이 준비되지 않았거나 권한 범위를 확인하지 못함.
- 게시물이 광고, 저작권 콘텐츠, 개인정보, 고객/회사 비공개 정보를 포함할 가능성이 있음.
- 공개 범위나 대상 계정을 사람이 최종 확인하지 않음.
- TikTok 앱이 감사되지 않았는데 공개 게시 성공으로 간주하려 함.
- TikTok을 개인 또는 내부 팀 계정만 관리하는 전용 업로더로 배포하려 함. 현재 공식 공유 지침의 허용 목적과 충돌할 수 있으므로 정책 검토가 필요함.
- Instagram 계정이 Business/Creator가 아니거나 필요한 게시 권한을 받지 못함.
- Telegram Bot이 대상 채널의 게시 관리자가 아님.
- X 요청별 현재 가격과 지출 한도를 확인하지 않음.
- KakaoTalk 메시지를 공개 커뮤니티 게시 또는 불특정 다수 자동 발송으로 오해함.
- Naver Blog/Cafe/Band를 쿠키·비밀번호·화면 매크로로 우회 게시하려 함.
- Naver Cafe 이미지, Discord 파일, Reddit 미디어, LinkedIn 자산, X 미디어 또는 YouTube 영상을 미완성 업로드 경로로 보내려 함.
- Facebook Page 권한과 Page access token을 개발 Page에서 검증하지 않음.
- Discord Webhook URL을 일반 URL처럼 로그·문서·Git에 저장하려 함.
- subreddit 규칙 또는 플랫폼의 광고·스팸·저작권 정책을 사람이 검토하지 않음.
- 실제 API 응답 ID와 최종 게시 상태를 확인하지 못함.
