COMMUNITY SETUP

Discord

Incoming Webhook 텍스트·원격 링크

1. 커뮤니티 사이트에서 설정할 부분

  1. 서버의 대상 채널 설정을 연다.
  2. 연동에서 Incoming Webhook을 만들고 채널을 지정한다.
  3. Webhook URL을 복사하고 노출되면 재생성한다.

공식 문서: Webhook Resource

2. 사이트에서 가져올 값과 환경 설정

환경변수가져올 값취급
DISCORD_WEBHOOK_URLID와 토큰을 포함한 전체 Webhook URL비밀값
$env:DISCORD_WEBHOOK_URL="본인이 발급·확인한 값"

.env.example은 변수명 참고용입니다. 현재 앱은 .env를 자동으로 읽지 않으므로 실제 값은 실행할 PowerShell 세션 또는 비밀 저장소에 설정합니다.

3. 설정 존재 여부 확인

python doctor.py --platform discord

READY는 값 존재만 뜻하며 유효한 토큰·권한·게시 성공을 보증하지 않습니다.

4. 외부 전송 없는 드라이런

python cli.py discord --text "설정 테스트"

실제 전송에는 --execute --confirm이 모두 필요합니다.

5. 실제 연결 테스트 전 HOLD

Webhook URL 자체가 비밀값이다. 파일 multipart는 HOLD다.

  • 토큰을 채팅·HTML·Git·로그에 넣지 않습니다.
  • 합성 테스트 문구만 사용합니다.
  • 대상·본문·비용을 사람이 확인한 뒤 실제 전송합니다.
