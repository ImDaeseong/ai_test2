COMMUNITY SETUP

Naver Cafe

공식 Cafe 텍스트·링크 글쓰기

1. 커뮤니티 사이트에서 설정할 부분

  1. Naver Developers에 네이버 로그인 앱을 등록한다.
  2. Cafe API 권한·Redirect URI·사용자 OAuth 동의를 구성한다.
  3. 대상 카페 ID와 게시판 menu ID를 확인한다.

공식 문서: Cafe 글쓰기

2. 사이트에서 가져올 값과 환경 설정

환경변수가져올 값취급
NAVER_ACCESS_TOKEN네이버 로그인 OAuth 토큰비밀값
NAVER_CAFE_ID카페 숫자 ID식별값
NAVER_CAFE_MENU_ID게시판 숫자 ID식별값
$env:NAVER_ACCESS_TOKEN="본인이 발급·확인한 값"
$env:NAVER_CAFE_ID="본인이 발급·확인한 값"
$env:NAVER_CAFE_MENU_ID="본인이 발급·확인한 값"

.env.example은 변수명 참고용입니다. 현재 앱은 .env를 자동으로 읽지 않으므로 실제 값은 실행할 PowerShell 세션 또는 비밀 저장소에 설정합니다.

3. 설정 존재 여부 확인

python doctor.py --platform naver_cafe

READY는 값 존재만 뜻하며 유효한 토큰·권한·게시 성공을 보증하지 않습니다.

4. 외부 전송 없는 드라이런

python cli.py naver_cafe --title "카페 제목" --text "카페 본문"

실제 전송에는 --execute --confirm이 모두 필요합니다.

5. 실제 연결 테스트 전 HOLD

multipart 이미지 첨부는 후속 범위다.

  • 토큰을 채팅·HTML·Git·로그에 넣지 않습니다.
  • 합성 테스트 문구만 사용합니다.
  • 대상·본문·비용을 사람이 확인한 뒤 실제 전송합니다.
