Naver 공유

사용자 주도 공유 화면

1. 커뮤니티 사이트에서 설정할 부분

  1. 별도 개발자 앱이나 토큰 설정은 필요하지 않다.
  2. 공유할 공개 HTTPS URL과 제목을 준비한다.
  3. 공유 화면에서 사용자가 로그인·편집·전송한다.

공식 문서: Naver 공유

2. 사이트에서 가져올 값과 환경 설정

필수 환경변수가 없습니다.

.env.example은 변수명 참고용입니다. 현재 앱은 .env를 자동으로 읽지 않으므로 실제 값은 실행할 PowerShell 세션 또는 비밀 저장소에 설정합니다.

3. 설정 존재 여부 확인

python doctor.py --platform naver

READY는 값 존재만 뜻하며 유효한 토큰·권한·게시 성공을 보증하지 않습니다.

4. 외부 전송 없는 드라이런

python cli.py naver --title "공유 제목" --text "공유 제목" --media-url "https://example.com/article"

실제 전송에는 --execute --confirm이 모두 필요합니다.

5. 실제 연결 테스트 전 HOLD

자동 게시가 아니며 사용자의 최종 조작 없이 실행하지 않는다.

  • 토큰을 채팅·HTML·Git·로그에 넣지 않습니다.
  • 합성 테스트 문구만 사용합니다.
  • 대상·본문·비용을 사람이 확인한 뒤 실제 전송합니다.
