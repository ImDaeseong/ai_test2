COMMUNITY SETUP

LinkedIn

텍스트·사전 업로드 자산 URN

1. 커뮤니티 사이트에서 설정할 부분

  1. LinkedIn Developer 앱과 OAuth Redirect URI를 설정한다.
  2. 개인 또는 조직 게시 권한을 준비한다.
  3. 게시 주체의 person 또는 organization URN을 확인한다.

공식 문서: Posts API

2. 사이트에서 가져올 값과 환경 설정

환경변수가져올 값취급
LINKEDIN_ACCESS_TOKEN사용자 OAuth 토큰비밀값
LINKEDIN_AUTHOR_URNperson 또는 organization URN식별값
LINKEDIN_VERSION예: 202610; 선택값식별값
$env:LINKEDIN_ACCESS_TOKEN="본인이 발급·확인한 값"
$env:LINKEDIN_AUTHOR_URN="본인이 발급·확인한 값"
$env:LINKEDIN_VERSION="본인이 발급·확인한 값"

.env.example은 변수명 참고용입니다. 현재 앱은 .env를 자동으로 읽지 않으므로 실제 값은 실행할 PowerShell 세션 또는 비밀 저장소에 설정합니다.

3. 설정 존재 여부 확인

python doctor.py --platform linkedin

READY는 값 존재만 뜻하며 유효한 토큰·권한·게시 성공을 보증하지 않습니다.

4. 외부 전송 없는 드라이런

python cli.py linkedin --text "설정 테스트"

실제 전송에는 --execute --confirm이 모두 필요합니다.

5. 실제 연결 테스트 전 HOLD

바이너리 업로드는 HOLD이며 이미 발급된 미디어 URN만 연결한다.

  • 토큰을 채팅·HTML·Git·로그에 넣지 않습니다.
  • 합성 테스트 문구만 사용합니다.
  • 대상·본문·비용을 사람이 확인한 뒤 실제 전송합니다.
