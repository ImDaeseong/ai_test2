COMMUNITY SETUP

Facebook Page

Page 텍스트·링크·원격 미디어

1. 커뮤니티 사이트에서 설정할 부분

  1. Meta 앱과 Facebook Login을 설정한다.
  2. 대상 Page의 관리 역할과 게시 권한을 승인받는다.
  3. 개발 Page에서 Page ID와 Page token의 대상을 확인한다.

공식 문서: Pages API

2. 사이트에서 가져올 값과 환경 설정

환경변수가져올 값취급
FACEBOOK_PAGE_ID게시 대상 Page ID식별값
FACEBOOK_PAGE_ACCESS_TOKENPage access token비밀값
META_GRAPH_VERSION예: v24.0; 선택값식별값
$env:FACEBOOK_PAGE_ID="본인이 발급·확인한 값"
$env:FACEBOOK_PAGE_ACCESS_TOKEN="본인이 발급·확인한 값"
$env:META_GRAPH_VERSION="본인이 발급·확인한 값"

.env.example은 변수명 참고용입니다. 현재 앱은 .env를 자동으로 읽지 않으므로 실제 값은 실행할 PowerShell 세션 또는 비밀 저장소에 설정합니다.

3. 설정 존재 여부 확인

python doctor.py --platform facebook_page

READY는 값 존재만 뜻하며 유효한 토큰·권한·게시 성공을 보증하지 않습니다.

4. 외부 전송 없는 드라이런

python cli.py facebook_page --text "Page 설정 테스트"

실제 전송에는 --execute --confirm이 모두 필요합니다.

5. 실제 연결 테스트 전 HOLD

실제 Page 역할·권한을 개발 Page에서 확인해야 하며 Reels는 HOLD다.

  • 토큰을 채팅·HTML·Git·로그에 넣지 않습니다.
  • 합성 테스트 문구만 사용합니다.
  • 대상·본문·비용을 사람이 확인한 뒤 실제 전송합니다.
