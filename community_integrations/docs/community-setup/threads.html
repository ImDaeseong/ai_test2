COMMUNITY SETUP

Threads

텍스트·공개 HTTPS 이미지·영상

1. 커뮤니티 사이트에서 설정할 부분

  1. Meta for Developers에서 Threads 사용 사례 앱을 만든다.
  2. OAuth Redirect URI를 등록한다.
  3. threads_basic, threads_content_publish 권한을 요청하고 사용자 동의를 완료한다.

공식 문서: Threads API

2. 사이트에서 가져올 값과 환경 설정

환경변수가져올 값취급
THREADS_USER_IDThreads 사용자 ID식별값
THREADS_ACCESS_TOKEN사용자 액세스 토큰비밀값
$env:THREADS_USER_ID="본인이 발급·확인한 값"
$env:THREADS_ACCESS_TOKEN="본인이 발급·확인한 값"

.env.example은 변수명 참고용입니다. 현재 앱은 .env를 자동으로 읽지 않으므로 실제 값은 실행할 PowerShell 세션 또는 비밀 저장소에 설정합니다.

3. 설정 존재 여부 확인

python doctor.py --platform threads

READY는 값 존재만 뜻하며 유효한 토큰·권한·게시 성공을 보증하지 않습니다.

4. 외부 전송 없는 드라이런

python cli.py threads --text "설정 테스트"

실제 전송에는 --execute --confirm이 모두 필요합니다.

5. 실제 연결 테스트 전 HOLD

미디어는 공개 HTTPS URL이 필요하며 실제 게시 전 앱 권한과 대상 계정을 확인한다.

  • 토큰을 채팅·HTML·Git·로그에 넣지 않습니다.
  • 합성 테스트 문구만 사용합니다.
  • 대상·본문·비용을 사람이 확인한 뒤 실제 전송합니다.
