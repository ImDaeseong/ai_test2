본인에게 메시지 보내기

1. 커뮤니티 사이트에서 설정할 부분

  1. Kakao Developers에 앱과 Redirect URI를 등록한다.
  2. 카카오 로그인과 동의 항목을 구성한다.
  3. 친구 발송은 별도 심사가 필요함을 구분한다.

공식 문서: 카카오톡 메시지

2. 사이트에서 가져올 값과 환경 설정

환경변수가져올 값취급
KAKAO_ACCESS_TOKEN카카오 로그인 사용자 토큰비밀값
$env:KAKAO_ACCESS_TOKEN="본인이 발급·확인한 값"

.env.example은 변수명 참고용입니다. 현재 앱은 .env를 자동으로 읽지 않으므로 실제 값은 실행할 PowerShell 세션 또는 비밀 저장소에 설정합니다.

3. 설정 존재 여부 확인

python doctor.py --platform kakao

READY는 값 존재만 뜻하며 유효한 토큰·권한·게시 성공을 보증하지 않습니다.

4. 외부 전송 없는 드라이런

python cli.py kakao --text "검토할 초안"

실제 전송에는 --execute --confirm이 모두 필요합니다.

5. 실제 연결 테스트 전 HOLD

카카오채널 공개 게시 API가 아니다. 현재는 본인 메시지만 지원한다.

  • 토큰을 채팅·HTML·Git·로그에 넣지 않습니다.
  • 합성 테스트 문구만 사용합니다.
  • 대상·본문·비용을 사람이 확인한 뒤 실제 전송합니다.
