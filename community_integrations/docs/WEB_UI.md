# 통합 커뮤니티 게시 웹 화면

## 무엇이 가능한가

`Community Canvas`는 13개 플랫폼의 지원 범위와 계정 설정 상태를 한 화면에서 확인하고, 게시물을 작성·미리보기·전송하는 로컬 웹 도구입니다. Canva 제품이나 상표를 복제하지 않고, 카드형 편집기와 즉시 미리보기라는 익숙한 사용 방식만 적용했습니다.

현재 웹 화면에서 실제 어댑터까지 연결되는 범위는 기존 CLI와 같습니다.

- 글, 공개 HTTPS 미디어 URL, 사전 업로드된 미디어 ID/URN: 플랫폼별 지원 범위에서 게시 가능
- 컴퓨터의 그림·영상·음악·문서 파일: 브라우저 미리보기 가능, 실제 업로드는 HOLD
- 지원하지 않는 플랫폼/형식: 실제 전송 전에 HOLD 메시지 표시
- 안전 미리보기: 네트워크 요청 없이 토큰이 제거된 요청 구조 표시
- 실제 게시: 확인 체크와 선택 플랫폼 ID 입력이 모두 맞을 때만 실행

따라서 **모든 파일 형식을 모든 플랫폼에 직접 업로드하는 개발까지 끝난 상태는 아닙니다.** 플랫폼마다 서로 다른 바이너리 업로드·미디어 처리 API를 추가해야 합니다.

## 실행 방법

Python 3.11 이상에서 다음 명령을 실행합니다.

```powershell
cd <AI_TEST2_ROOT>\community_integrations
python web_app.py
```

브라우저에서 `http://127.0.0.1:8766`을 엽니다. 서버는 이 PC에서만 접근 가능한 `127.0.0.1`에 연결됩니다.

## 초보자 사용 순서

1. 왼쪽 목록에서 게시할 플랫폼을 선택합니다.
2. 화면의 `설정 필요` 항목을 보고 `.env.example`의 환경 변수 이름을 확인합니다.
3. 제목, 내용, 콘텐츠 형식을 입력합니다.
4. 이미지나 영상은 우선 플랫폼이 읽을 수 있는 공개 `https://` URL을 입력합니다.
5. `안전 미리보기 만들기`를 눌러 게시 요청 내용을 확인합니다.
6. 실제 전송이 필요할 때만 `실제 게시 열기`를 펼칩니다.
7. 최종 확인 체크 후 선택한 플랫폼 ID(예: `telegram`)를 직접 입력하고 실행합니다.

## 파일 업로드가 HOLD인 이유

로컬 파일은 브라우저 안에서만 볼 수 있고 Instagram, Threads, TikTok 같은 외부 플랫폼 서버가 그 파일을 직접 읽을 수 없습니다. 플랫폼에 따라 다음 중 하나가 필요합니다.

- 공개 HTTPS 저장소에 먼저 업로드한 뒤 URL 전달
- 플랫폼의 초기화 API로 업로드 URL을 받고 바이너리 전송
- multipart/form-data 파일 업로드
- resumable/chunked 업로드와 완료 상태 확인

이 과정은 인증, 파일 크기, 형식, 저작권, 처리 상태가 플랫폼마다 달라 공통 업로드처럼 처리하면 안 됩니다.

## 현재 보안 경계

- 노출 등급: T0 로컬 전용
- 기본 바인딩: `127.0.0.1`
- JSON 요청 제한: 64 KiB
- API 토큰: 브라우저로 전달하거나 응답에 표시하지 않음
- dry-run: 외부 네트워크 호출 없음
- 실제 게시: 체크박스와 플랫폼 ID 재입력 필요
- 로컬 파일: 서버로 업로드하지 않음
