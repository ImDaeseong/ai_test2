# 커뮤니티 자동 게시 통합 조사

확인일: 2026-10-27

## 결론

공식 API로 직접 게시 가능한 범위는 플랫폼마다 크게 다릅니다. Threads, Instagram Professional, Telegram Bot, TikTok Content Posting API, X API는 공식 게시 경로가 있습니다. KakaoTalk 메시지는 본인/동의한 서비스 사용자 간 메시지이지 공개 커뮤니티 피드 게시가 아닙니다. NAVER Blog 글쓰기 API는 종료됐지만, Naver Cafe는 OAuth 기반 공식 글쓰기 API를 제공하며 Naver 공유하기는 사용자가 최종 전송하는 수동 경로입니다. 이 프로젝트는 Cafe 텍스트·링크 게시만 구현하고 multipart 이미지는 HOLD합니다.

## 증거 원장

| 판단 | 상태 | 확인한 공식 근거 | 구현 반영 |
|---|---|---|---|
| Threads는 컨테이너 생성 후 게시 가능 | 지원 | Meta 공식 Threads Postman 컬렉션과 fbsamples 예제 | `ThreadsAdapter` 2단계 실행 |
| Instagram은 Professional 계정 미디어 게시 가능 | 지원 | Meta 공식 Instagram Postman 컬렉션 | 개인 계정 제외, 컨테이너→게시 |
| Telegram Bot은 권한 있는 chat/channel에 텍스트·사진·영상 전송 가능 | 지원 | Telegram Bot API | Bot API 어댑터 |
| TikTok Direct Post는 사진·영상과 상태 조회를 지원 | 지원(조건부) | TikTok Direct Post/상태/가이드 | 기본 `SELF_ONLY`, `publish_id` 반환 |
| 감사되지 않은 TikTok 클라이언트 게시물은 비공개 제한 | 지원(제한) | TikTok Content Sharing Guidelines | 공개 성공 주장 금지/HOLD |
| X는 `POST /2/tweets`를 제공하고 요청별 과금 | 지원(유료) | X Create Posts와 Pricing | 미리보기 기본, 비용 HOLD |
| KakaoTalk API는 같은 서비스 사용자 간/본인 메시지 | 부분 지원 | KakaoTalk 메시지 이해하기/FAQ | 본인 메시지만, 공개 게시로 표기 금지 |
| Naver Cafe는 OAuth 글쓰기 API를 제공하고 Blog 글쓰기는 종료됨 | 부분 지원 | Naver Cafe 글쓰기 API, Blog API 종료 공지, Naver 공유하기 | Cafe 텍스트·링크 실행, 이미지 multipart HOLD, 공유 URL은 수동 |

## 반대 가능성과 한계

- 플랫폼 문서는 수시로 바뀝니다. 실제 앱 콘솔 권한이 최종 계약입니다.
- Meta 개발자 문서는 조사 도구에서 429/접근 제한이 발생해 Meta가 관리하는 공식 Postman 컬렉션과 공식 샘플 저장소를 교차 확인했습니다.
- Naver는 서비스별 계약이 다릅니다. Cafe 글쓰기, 종료된 Blog 글쓰기, 사용자 주도 공유 화면을 하나의 자동 게시 기능으로 묶어 해석하지 않습니다.
- 오프라인 테스트는 요청 형식과 안전 게이트를 검증할 뿐 OAuth 심사, 계정 권한, 미디어 처리, 과금, 플랫폼 검수를 검증하지 않습니다.
