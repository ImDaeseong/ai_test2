1. Access Token 설정

현재 연결에 필요한 값은 Access Token 하나입니다. 실제 토큰은 웹페이지나 파일에 입력하지 말고, Studio를 실행할 PowerShell 창에서만 설정합니다.

cd "<AI_TEST2_ROOT>\community_integrations\threads"
$env:THREADS_ACCESS_TOKEN="본인의 Threads 사용자 토큰"
.\start.bat

2. 계정 정보 가져오기

  1. 위 명령으로 Studio를 다시 실행합니다.
  2. 계정 정보 가져오기를 누릅니다.
  3. 표시된 Threads 사용자명과 ID가 내 계정인지 확인합니다.

토큰은 어디서 준비하나?

Meta 앱에 Threads 사용 사례를 추가하고 threads_basic, threads_content_publish 권한으로 사용자 동의를 거쳐 발급합니다. 토큰을 이 채팅, HTML, 배치 파일 또는 Git에 저장하지 마십시오.
