Threads 연동은 디지털 우체국입니다

내 프로그램이 내 대신 Threads에 글이나 그림을 올리도록 허락하는 과정을 가장 쉬운 말로 설명합니다.

📮 우체국으로 생각하면 쉽습니다.
프로그램은 편지를 쓰는 사람, Threads API는 우체국 창구, 액세스 토큰은 출입증, 컨테이너 ID는 접수번호, 게시물 ID는 실제 배달이 끝난 편지 번호입니다.

왜 번호가 두 개일까?

1

내용을 접수합니다

글이나 공개 미디어 URL을 보내면 컨테이너 ID를 받습니다. 아직 게시 완료가 아닙니다.

↓
2

Threads가 준비합니다

그림과 영상을 내려받아 처리합니다. 상태가 FINISHED가 될 때까지 기다립니다.

↓
3

게시를 확정합니다

게시 요청 뒤 게시물 ID를 받아야 성공으로 기록합니다.

올릴 수 있는 것

✍️

글과 링크

TEXT로 본문과 링크를 보냅니다.

🖼️

그림

Threads가 인터넷에서 읽을 수 있는 이미지 주소가 필요합니다.

🎬

영상

공개 영상 주소를 보내고 처리 상태를 확인합니다.

🎵

음악

MP3 단독 유형은 없습니다. 음악 포함 영상이나 링크로 다룹니다.

내 컴퓨터 경로는 사용할 수 없습니다

C:\사진\그림.jpg는 내 컴퓨터에서만 보입니다. 먼저 안전한 웹 저장소에 올려 Threads가 읽을 수 있는 임시 공개 URL을 만들어야 합니다.

토큰은 무엇인가?

사용자가 Meta 로그인 화면에서 게시 권한을 허용하면 프로그램이 토큰을 받습니다. 토큰은 비밀번호처럼 다루며 문서, Git, 브라우저 로그에 적지 않습니다. 앱 시크릿을 사용하는 토큰 교환과 보관은 서버가 담당합니다.

안전하게 예제 보기

python examples\threads_python\cli.py text --text "안녕하세요"
python examples\threads_python\cli.py image --url "https://example.com/image.jpg" --alt-text "예시 그림"

기본 실행은 실제 게시를 하지 않고 요청 모양만 보여 줍니다. --execute와 실제 환경변수가 함께 있을 때만 네트워크 게시를 시도합니다.

세 가지만 기억하세요

  1. 토큰은 소스와 문서에 적지 않습니다.
  2. 컨테이너 생성과 게시 성공은 다른 단계입니다.
  3. 공식 문서와 실제 앱 설정을 확인한 뒤 운영합니다.
