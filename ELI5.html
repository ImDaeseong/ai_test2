Marketing Command Center

Threads·X·카카오·네이버·Instagram·Reels·TikTok 등 채널의 초안, 승인, 일정과 성과를 관리합니다.

마케팅 도구는 로컬 운영 화면입니다. 계정 설정값을 감지할 수 있지만 실제 계정 연결이나 게시 완료를 뜻하지 않습니다. 실제 OAuth 연결과 게시는 각 플랫폼의 계정·권한과 사람 승인이 필요합니다.
CareerDiff의 OpenAI 모드는 외부 전송 전에 화면과 서버에서 동의를 확인합니다. 키가 없으면 로컬 분석기를 사용합니다. 실제 키는 저장소에 넣지 않습니다.

가장 쉬운 마케팅 화면 실행

cd marketing_command_center start.bat

브라우저가 열리지 않으면 python serve.py 실행 후 http://127.0.0.1:4173을 엽니다.

검증

cd marketing_command_center npm test python -m unittest discover -s tests -v npm run validate python scripts/smoke_lifecycle.py npm run e2e
